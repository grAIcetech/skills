# Inspiration sites — `/beautify`'s visual-reference seed list

Starting suggestions for the "Visual references" round when nothing else comes to
mind. Not a ruling — just candidates to react to ("borrow the X from this, skip the
rest"). This list is meant to grow: add a row any time a session surfaces a site worth
reusing, so later runs of `/beautify` in this project start with a fuller list. Keep
entries short.

| Site | What's worth borrowing |
|---|---|
| [motionsites.ai](https://motionsites.ai/) | Motion-forward, interaction-led site design — scroll-triggered reveals, cursor-reactive detail, kinetic type. Good default when a project wants to feel alive/current rather than static. |
